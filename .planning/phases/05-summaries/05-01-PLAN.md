1. Add to src/domain/summary.ts -- add computeDailySummary and computeWeeklySummary functions (keep existing MOOD_SCORE and getWeekRange):

computeDailySummary(dayKey: string): Promise<DailySummary>
- Query db.tasks where status='completed' AND completedAt falls within dayKey T00:00:00 to T23:59:59.999
- Query db.tasks where createdAt falls within same range (for tasksCreated count)
- Query db.pointLedger where createdAt falls within same range. Sum positive amounts as pointsEarned, sum absolute value of negative amounts as pointsSpent
- Query db.moodEntries where createdAt falls within same range
- Query db.redemptions where createdAt falls within same range
- Determine dominantMood: count frequency of each emoji in mood entries, pick highest count. If tie, pick first encountered. If no moods, set dominantMood to null and dominantMoodScore to 0
- Return a DailySummary object with generateId() as id, all collected data, and computedAt = new Date()

computeWeeklySummary(weekStartDate: string): Promise<WeeklySummary>
- Get week range using getWeekRange(new Date(weekStartDate + 'T12:00:00'))
- For each day in Mon-Sun range, call computeDailySummary internally (or aggregate directly from DB for efficiency)
- totalTasksCompleted = sum of daily tasksCompleted
- totalTasksCreated = sum of daily tasksCreated
- totalPointsEarned = sum of daily pointsEarned
- totalPointsSpent = sum of daily pointsSpent
- avgMoodScore = average of daily dominantMoodScore values (excluding 0s), 0 if all 0
- streakDays = count of db.streakRecords where date falls within weekStart-weekEnd range
- completionRate = totalTasksCompleted / totalTasksCreated, 0 if totalTasksCreated === 0 (D-13)
- For each day, calculate compositeScore = tasksCompleted*0.4 + moodScore*0.3 + pointsEarned*0.3 (D-11). Normalize points: divide by POINT_VALUES.hard (50) so points factor is 0-1 range. The formula becomes: tasksCompleted * 0.4 + moodScore/5 * 0.3 + Math.min(pointsEarned/50, 1) * 0.3
- bestDayDate = dayKey with highest compositeScore. Ties broken by tasksCompleted (D-11)
- bestDayScore and bestDayTaskCount stored for reference
- userBestDayOverride = null by default (D-12)
- Return WeeklySummary with generateId() as id and computedAt = new Date()
