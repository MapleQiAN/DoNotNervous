## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Action function -> summary refresh | Internal async call, non-blocking, no user input |
| useLiveQuery -> Dexie table | Reactive read from local IndexedDB, trusted data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03 | Denial of Service | Multiple refresh triggers on rapid actions | accept | Each refresh overwrites same dayKey, Dexie put is idempotent; rapid completions cause re-computation but bounded by DB size |
| T-05-04 | Information Disclosure | Summary data in IndexedDB | accept | Local-only data, no network transmission; IndexedDB protected by browser same-origin policy |
