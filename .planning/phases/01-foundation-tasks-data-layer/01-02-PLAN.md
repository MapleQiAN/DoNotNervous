**1. Create src/hooks/useTaskCount.ts**
Simple hook that returns the total count of tasks for progressive disclosure logic:
```typescript
import { useLiveQuery } from 'dexie-react-hooks'
import { db } from '../db'

export function useTaskCount(): number {
  return useLiveQuery(
    () => db.tasks.where('status').equals('active').count(),
    [],
    0
  )
}
```

**4. Create src/components/tasks/TaskList.tsx**
Scrollable task list with active and completed sections.

Data fetching with useLiveQuery:
```typescript
const activeTasks = useLiveQuery(
  () => db.tasks
    .where('status').equals('active')
    .sortBy('sortOrder'),
  [],
  []
)

const completedTasks = useLiveQuery(
  () => db.tasks
    .where('status').equals('completed')
    .reverse()
    .sortBy('completedAt'),
  [],
  []
)
```

Filter by category if activeCategory is set:
```typescript
const filtered = activeCategory
  ? activeTasks.filter(t => t.category === activeCategory)
  : activeTasks
```

Note: Only show top-level tasks (parentId === null). Subtasks are handled by SubtaskList within each TaskItem.

Layout:
- If no active tasks and no completed tasks: show EmptyState "Nothing here yet" / "Add your first task to get started. One small step counts."
- Active tasks section: map over filtered tasks, render TaskItem for each, wrapped in framer-motion AnimatePresence
- Subtasks rendered inside each TaskItem via SubtaskList
- Completed section: collapsible section with header "Completed (N)" using Lucide ChevronDown/ChevronUp toggle. Shows completed tasks with TaskItem (completed state).
- CategoryFilter appears above task list if total task count >= 3 (use useTaskCount hook)

Wrap the entire list in framer-motion AnimatePresence for add/remove animations.

Props: none (self-contained with useLiveQuery and store subscriptions)

**6. Create src/components/tasks/CategoryFilter.tsx**
Horizontal scrollable chip bar.

Data: derive unique categories from all active tasks:
```typescript
const categories = useLiveQuery(
  async () => {
    const tasks = await db.tasks.where('status').equals('active').toArray()
    const unique = [...new Set(tasks.map(t => t.category).filter(Boolean))]
    return unique.sort()
  },
  [],
  []
)
```

Layout: flex gap-2 overflow-x-auto pb-2 mb-4 (horizontal scroll, no wrap).
Each chip: Button variant="ghost" with rounded-full. Active chip uses bg-lavender-500 text-white. Inactive uses bg-cream-100 text-text-primary.
"All" chip always present (resets filter to null).

Props: none (reads from filterStore and db)
