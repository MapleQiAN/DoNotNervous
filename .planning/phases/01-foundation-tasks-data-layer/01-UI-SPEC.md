# Phase 1 — UI Design Contract

> Visual and interaction contract for the Foundation phase (Tasks & Data Layer).
> Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (custom Tailwind v4 components) |
| Preset | not applicable — no shadcn, building bespoke anti-anxiety design |
| Component library | none — custom React components with Tailwind v4 + clsx + tailwind-merge |
| Icon library | Lucide React 0.514.0 — lightweight, soft stroke style fits calming aesthetic, tree-shakeable |
| Font | Inter (variable weight) via Google Fonts — neutral, highly legible, works at small sizes on mobile |

**Rationale:** shadcn was evaluated and deliberately excluded. The RESEARCH.md states: "Not MUI/Chakra: Opinionated designs don't match the 'cute/playful' aesthetic we need." The anti-anxiety wellness app requires a bespoke warm, gentle visual identity that generic component libraries cannot provide. All components are built custom with Tailwind v4 utility classes.

**Lucide React chosen because:** Soft 1.5px stroke weight (not harsh), consistent 24px grid, tree-shakeable ESM imports, actively maintained, MIT license. Fits the "gentle, warm" aesthetic better than Heroicons (thicker strokes) or Phosphor (too many style variants cause decision fatigue).

**Inter chosen because:** Variable font supports weights 100-900 in a single file download. Excellent at 14-16px on mobile screens. Neutral personality does not compete with the warm color palette. Free via Google Fonts with wide language support.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding, tight list item internal spacing |
| sm | 8px | Compact element spacing, task item inner padding, tag gaps |
| md | 16px | Default element spacing, form field gaps, card padding |
| lg | 24px | Section padding, card gaps in grid, header bottom margin |
| xl | 32px | Layout section gaps, major component separation |
| 2xl | 48px | Major section breaks, hero area padding |
| 3xl | 64px | Page-level vertical spacing, top-level container padding |

Exceptions: Touch targets must be minimum 44px height on interactive elements (checkbox, buttons, drag handles) for mobile accessibility. This is not a spacing value but a minimum dimension constraint.

**Tailwind v4 mapping:** These map directly to Tailwind's default 4px spacing scale (`p-1` = 4px, `p-2` = 8px, `p-4` = 16px, `p-6` = 24px, `p-8` = 32px, `p-12` = 48px, `p-16` = 64px). No custom `@theme` spacing overrides needed.

## Typography

| Role | Size | Weight | Line Height | Tailwind Class |
|------|------|--------|-------------|----------------|
| Body | 16px (1rem) | 400 (regular) | 1.5 (24px) | `text-base leading-relaxed font-normal` |
| Label | 14px (0.875rem) | 500 (medium) | 1.4 (19.6px) | `text-sm leading-snug font-medium` |
| Heading | 20px (1.25rem) | 600 (semibold) | 1.2 (24px) | `text-xl leading-tight font-semibold` |
| Display | 28px (1.75rem) | 600 (semibold) | 1.2 (33.6px) | `text-2xl leading-tight font-semibold` |

**Rules:**
- Exactly 4 sizes declared. No intermediate sizes.
- Exactly 2 weights: 400 (body text) and 600 (headings, labels, emphasis). Weight 500 is used only for small labels to create subtle hierarchy without adding a third conceptual weight.
- Completed task titles use `line-through` decoration + `opacity-60` for visual demotion.
- Task difficulty badges use Label size (14px) with colored backgrounds, never larger.

**Mobile consideration:** On viewports below 640px (`sm:` breakpoint), Display remains 28px. No scaling down. The content area narrows instead.

## Color

**Palette:** Warm, calming OKLCH colors. No saturated reds, no harsh contrasts. Inspired by wellness apps (Finch, Calm) with a lavender-cream base.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `oklch(0.98 0.008 280)` — warm cream white | Page background, card surfaces, input fields |
| Secondary (30%) | `oklch(0.94 0.015 280)` — soft lavender white | Card backgrounds on colored sections, sidebar, elevated surfaces, task item hover state |
| Accent (10%) | `oklch(0.72 0.14 300)` — gentle lavender purple | CTA button, active category chip, task completion checkmark, links, drag handle focus ring |
| Destructive | `oklch(0.65 0.12 25)` — muted warm red | Delete button icon only (never full background), delete confirmation dialog border |

**Accent reserved for:**
1. Primary CTA button background ("Add Task")
2. Task completion checkmark circle (filled)
3. Active/selected category filter chip background
4. Link text color
5. Focus ring on interactive elements (accessibility)

**Accent is NOT used for:**
- Decorative elements, section dividers, or general UI chrome
- Text highlighting or background tints on large areas
- Headers or navigation bars

**Additional semantic colors:**

| Name | Value | Usage |
|------|-------|-------|
| Success | `oklch(0.72 0.14 160)` — soft sage green | Completed task badge, success toast |
| Difficulty-Easy | `oklch(0.78 0.10 160)` — light sage | Easy difficulty badge background |
| Difficulty-Medium | `oklch(0.78 0.08 80)` — warm amber | Medium difficulty badge background |
| Difficulty-Hard | `oklch(0.72 0.12 25)` — soft coral | Hard difficulty badge background |
| Text Primary | `oklch(0.22 0.02 280)` — warm near-black | Body text, headings |
| Text Secondary | `oklch(0.48 0.02 280)` — warm gray | Description text, timestamps, hint text |
| Border | `oklch(0.90 0.01 280)` — subtle warm border | Input borders, card borders, dividers |

**Tailwind v4 `@theme` definition:**

```css
@theme {
  --color-cream-50: oklch(0.98 0.008 280);
  --color-cream-100: oklch(0.94 0.015 280);
  --color-lavender-500: oklch(0.72 0.14 300);
  --color-lavender-100: oklch(0.92 0.04 300);
  --color-sage-500: oklch(0.72 0.14 160);
  --color-amber-500: oklch(0.78 0.08 80);
  --color-coral-500: oklch(0.72 0.12 25);
  --color-text-primary: oklch(0.22 0.02 280);
  --color-text-secondary: oklch(0.48 0.02 280);
  --color-border: oklch(0.90 0.01 280);
}
```

**Anti-anxiety color rules:**
- Never use pure black (#000) for text — always use warm near-black.
- Never use saturated red for errors — use muted coral, and only on delete actions.
- Background is never pure white — always warm cream.
- Completed tasks fade to 60% opacity, never gray strikethrough (too punitive feeling).
- Success/celebration colors are warm and soft, never neon or high-saturation.

## Copywriting Contract

All copy uses positive, encouraging framing. Never punitive, never guilt-inducing. First person not used — the app speaks gently in second person or just states facts.

| Element | Copy |
|---------|------|
| Primary CTA | **Add Task** — on the main submit button in the task input area |
| Empty state heading | Nothing here yet |
| Empty state body | Add your first task to get started. One small step counts. |
| Empty category heading | No tasks in this category |
| Empty category body | Try selecting a different category or add a new task. |
| Empty archive heading | No completed tasks |
| Empty archive body | Tasks you finish will show up here. |
| Error state (general) | Something went wrong. Try again — your data is safe. |
| Error state (import fail) | Could not import this file. Make sure it is a DoNotNervous backup. |
| Delete task confirmation | Delete this task? — as confirmation dialog heading |
| Delete task body | This cannot be undone. Subtasks will also be removed. |
| Delete task CTA | Delete — destructive button; Cancel — dismiss button |
| Archive action label | Archive — on completed tasks |
| Unarchive action label | Restore — on archived tasks |
| Export success toast | Backup saved — your data is safe. |
| Import success toast | Data restored successfully. |
| Difficulty labels | Easy / Medium / Hard — displayed as badges |
| Category placeholder | Type a category name... — input placeholder |
| Task title placeholder | What would you like to do? — main task input placeholder |
| Task description placeholder | Add a note (optional) — description input placeholder |
| Subtask placeholder | Add a subtask... — subtask input placeholder |

**Anti-anxiety copywriting rules:**
- Never use words like: fail, wrong, error (except in technical error states where it is necessary), late, missed, behind.
- Completed tasks are celebrated, not "done" with indifference.
- Empty states are opportunities, not failures. "Nothing here yet" not "You have no tasks."
- Error messages always reassure: "your data is safe."
- Confirmation dialogs are simple and clear, not dramatic. "Delete this task?" not "Are you absolutely sure you want to permanently delete this task?"

## Interaction Patterns

### Task Completion Animation (TASK-02)

When user taps the checkbox to complete a task:
1. Checkbox circle fills with accent lavender color (Motion scale spring: [1, 1.2, 1], duration 300ms)
2. White checkmark draws inside (SVG path animation, 200ms)
3. Task title gets `line-through` + `opacity-60` transition (300ms ease)
4. After 1.5 second delay, task slides down to completed section with Motion exit animation (opacity 0, y: 20, 200ms)

This is a satisfying but not flashy animation. No confetti in Phase 1 (deferred to Phase 4).

### Task Add Animation (TASK-01)

New task slides in from top with Motion:
- `initial={{ opacity: 0, y: -10 }}`
- `animate={{ opacity: 1, y: 0 }}`
- `transition={{ type: "spring", stiffness: 400, damping: 30 }}`

### Task Delete Animation (TASK-03)

Deleted task shrinks out:
- `exit={{ opacity: 0, scale: 0.95, height: 0, marginTop: 0, marginBottom: 0 }}`
- Duration: 200ms ease

### Drag Reorder (TASK-06)

- Drag handle appears on hover/focus (grip-vertical Lucide icon)
- Lifted item gets subtle shadow (`shadow-md`) and slight scale (`scale: 1.02`)
- Drop zone indicated by gap opening in list (dnd-kit default sortable strategy)
- After drop, `sortOrder` persists to Dexie

### Progressive Disclosure (ONBD-02)

- First visit: only title input + "Add Task" button visible
- Category, difficulty, description, subtask fields are hidden behind "More options" toggle (Lucide chevron-down icon)
- After adding 3+ tasks, category filter bar appears automatically above the task list
- Archive view accessible via "Completed" tab, not shown initially

### Export/Import (DATA-04, DATA-05)

- Settings gear icon in header (top-right)
- Opens a slide-over drawer (not modal — less disruptive)
- Export button: "Save Backup" with download icon
- Import button: "Restore from Backup" with upload icon, triggers file picker
- Both show toast notifications on success/failure

## Layout

### Mobile (< 640px) — Primary Target

```
+-------------------------------------------+
| Header: "DoNotNervous" [gear icon]        |
+-------------------------------------------+
| TaskInput                                 |
| [What would you like to do?]  [Add Task]  |
| [More options v]                           |
+-------------------------------------------+
| CategoryFilter (if 3+ tasks)              |
| [All] [Work] [Personal] ...               |
+-------------------------------------------+
| TaskList (scrollable)                     |
| [ ] Buy groceries          [easy] [o]     |
| [ ] Read chapter 3       [medium] [o]     |
|    [ ] Take notes (subtask)               |
| [ ] Finish report           [hard] [o]    |
|                                           |
| --- Completed ---                         |
| [x] Morning stretches      [easy]         |
+-------------------------------------------+
```

- Full-width layout, no sidebar
- TaskInput is always visible at top (sticky on scroll)
- CategoryFilter horizontal scroll, no wrap
- TaskList takes remaining viewport height
- Completed section collapsible at bottom

### Desktop (>= 1024px)

```
+-------------------------------------------+
| Header: "DoNotNervous"          [gear]    |
+-------------------------------------------+
|                                           |
|   +-----------------------------------+   |
|   | TaskInput                         |   |
|   | [What would you like to do?]      |   |
|   | [Add Task]                        |   |
|   +-----------------------------------+   |
|   | CategoryFilter                    |   |
|   | [All] [Work] [Personal]           |   |
|   +-----------------------------------+   |
|   | TaskList                          |   |
|   | ...                               |   |
|   +-----------------------------------+   |
|                                           |
+-------------------------------------------+
```

- Max-width 640px centered container for task list (prevents eye strain on wide screens)
- Generous `lg` (24px) padding on sides
- Same vertical flow as mobile, just with horizontal centering and more breathing room
