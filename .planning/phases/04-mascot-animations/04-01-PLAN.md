    2. Create `src/stores/mascotStore.ts` — a Zustand store (NOT persisted — animation state resets on reload, which is correct). Pattern: `create<MascotState>()((set) => ({ ... }))`. Interface:
    ```typescript
    type MascotAnimation = 'idle' | 'celebrate' | 'encourage' | 'sleepy'

    interface MascotState {
      animation: MascotAnimation
      showSpeechBubble: boolean
      speechMessage: string
      setAnimation: (anim: MascotAnimation) => void
      triggerSpeech: (message: string) => void
      dismissSpeech: () => void
    }
    ```
    - `setAnimation` sets the animation. After setting 'celebrate' or 'encourage', auto-revert to 'idle' after 3 seconds using a setTimeout. Clear previous timeout on each call.
    - `triggerSpeech(message)` sets `showSpeechBubble: true` and `speechMessage: message`. Auto-dismiss after 3 seconds via setTimeout. If already showing, update message and reset timer.
    - `dismissSpeech()` sets `showSpeechBubble: false` and clears timer.
    - Default state: `animation: 'idle'`, `showSpeechBubble: false`, `speechMessage: ''`.

    3. Create `src/lib/celebrate.ts` — shared confetti utility. Import `confetti` from `canvas-confetti`. Export a single `celebrate` function:
    ```typescript
    export function celebrate(options: {
      particleCount: number
      spread: number
    }): void
    ```
    - Always uses `origin: { x: 0.85, y: 0.8 }` (bottom-right, near mascot position per D-09).
    - Always uses warm palette per D-10: `colors: ['#f7b955', '#f08a55', '#fbd58b', '#4f915b']`.
    - Calls `confetti({ ...options, origin, colors, startVelocity: 30, gravity: 0.8, ticks: 200 })`.

    4. Export pre-built event helpers alongside celebrate:
