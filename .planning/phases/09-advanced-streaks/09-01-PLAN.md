3. Implement `detectEarnBackOpportunity`:
   - Takes `now: Date = new Date()` as parameter
   - Returns `EarnBackOpportunity | null`
   - Logic:
     a. Get today's key via `toDayKey(now)`. If today already has a streak record with completedTaskIds.length > 0, return null (active day, no earn-back needed)
     b. Get all streakRecords ordered by date descending
     c. If no records exist, return null
     d. Find the most recent record. Compute gap days from that record to now
     e. If gap <= 1, return null (yesterday was active or today is still in progress)
     f. Count frozen days among gap days (records where freezeUsed=true or recoveredFrom=true). These are already "covered"
     g. Count unfrozen, unrecovered gap days = gap - 1 (exclude today) - frozenDays - recoveredDays
     h. If unfrozen gap < 1, return null (all gaps are covered by freezes/recoveries)
     i. Find the first unfrozen gap day's date. Compute hours since that day's start (use differenceInHours from that day at noon)
     j. If hoursSinceBreak > EARN_BACK_WINDOW_HOURS, return null (window expired)
     k. Count previousStreakLength by walking backward from the last record
     l. Return { previousStreakLength, gapDay, deadline }
   - IMPORTANT: This function operates on the database, so it must be async

4. Implement `applyEarnBackRecovery`:
   - Takes `recoveryTaskId: string` and `gapDayKey: string` as parameters
   - Returns `Promise<void>`
   - Logic (inside a db.transaction on streakRecords and pointLedger):
     a. Check if the gap day already has a record with `recoveredFrom === true`. If so, return early (idempotent guard)
     b. Get any existing record for the gap day
     c. Create/update the record via `db.streakRecords.put()` with:
        - date: gapDayKey
        - completedTaskIds: existing ? [...existing.completedTaskIds, recoveryTaskId] : [recoveryTaskId]
        - freezeUsed: existing?.freezeUsed ?? false
        - freezeCountRemaining: existing?.freezeCountRemaining ?? 0
        - createdAt: existing?.createdAt ?? new Date()
        - recoveredFrom: true
        - recoveryTaskId: recoveryTaskId
