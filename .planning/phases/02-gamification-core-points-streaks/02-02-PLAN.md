    **2. Rewrite src/hooks/useTaskActions.ts** -- Extend completeTask with atomic transaction:

    The new completeTask must wrap task status update + point ledger write + streak record update in a single `db.transaction('rw', [db.tasks, db.pointLedger, db.streakRecords], ...)`.

    Algorithm:
    1. Read task from DB to get difficulty and title
    2. Compute current streak length by calling a local helper `computeCurrentStreak(now)` that walks backward through streakRecords from today
    3. Call `calculatePoints(task.difficulty, streakLength)` to get base, bonus, multiplier
    4. Write task status update: `db.tasks.update(id, { status: 'completed', completedAt: now })`
    5. Write base ledger entry: `db.pointLedger.add({ id: generateId(), amount: base, type: 'task_complete', reason: 'Completed: ' + task.title, taskId: task.id, streakLength, multiplier, createdAt: now })`
    6. If bonus > 0, write bonus ledger entry: `db.pointLedger.add({ id: generateId(), amount: bonus, type: 'streak_bonus', reason: 'Streak bonus (' + multiplier + 'x)', taskId: task.id, streakLength, multiplier, createdAt: now })`
    7. Upsert today's streak record using `db.streakRecords.put()`: if exists, append taskId to completedTaskIds; if new, create with `{ date: toDayKey(now), completedTaskIds: [task.id], freezeUsed: false, freezeCountRemaining: 2, createdAt: now }`

    CRITICAL: Use `db.streakRecords.put()` (upsert), NOT `add()`, to prevent duplicate key errors on same-day re-completion.

    Helper `computeCurrentStreak(now)`:
    - Start from today's day key
    - Walk backward day by day, checking if a streakRecord exists for that day
    - If a day has no record and freezeUsed is not true, stop -- streak ends
    - Count consecutive days with records (including frozen days) as the streak length
    - Return the count

    uncompleteTask: Keep the existing implementation (just resets status/completedAt). Do NOT reverse points. This is the anti-anxiety principle from D-08 / STATE.md.

    **3. Create src/hooks/usePoints.ts** -- Reactive point balance and transaction history:

    ```typescript
    import { useLiveQuery } from 'dexie-react-hooks'
    import { db } from '../db'
    import type { PointLedgerEntry } from '../domain/types'

    export function usePointBalance(): number {
      return useLiveQuery(
        async () => {
          const entries = await db.pointLedger.toArray()
          return entries.reduce((sum, entry) => sum + entry.amount, 0)
        },
        [],
        0
      )
    }

    export function useRecentTransactions(limit = 10): PointLedgerEntry[] {
      return useLiveQuery(
        async () => db.pointLedger.orderBy('createdAt').reverse().limit(limit).toArray(),
        [],
        []
      )
    }
    ```

    **4. Create src/hooks/useStreaks.ts** -- Reactive streak state and freeze logic:

    This hook provides:
    - `useCurrentStreak()` -- useLiveQuery that computes current streak length by reading all streakRecords and walking backward from today
    - `useStreakFreezes()` -- returns number of freezes remaining (always starts at 2, decremented by freeze usage per D-07)
    - `checkAndApplyFreezes(showToast: (msg: string) => void)` -- called on app load and after task completion. Algorithm:
      1. Get last streakRecord date
      2. Calculate gap days between last record and today
      3. If gap > 0 and gap <= 2 (available freezes): insert frozen streakRecords for the gap days with `freezeUsed: true`, `completedTaskIds: []`
      4. Each freeze record decrements freezeCountRemaining
      5. Show Toast: "Your streak is safe! (N freeze remaining)" -- positive framing per STRK-04
      6. If gap > 2 (more missed days than freezes): apply all available freezes, then streak breaks after that

    Freeze records are created with:
    ```typescript
    {
      date: dayKey,
      completedTaskIds: [],
      freezeUsed: true,
      freezeCountRemaining: remainingAfterThisUse,
      createdAt: new Date()
    }
    ```

    Per D-07: freezes "reset after use" means the user always has 2 available. So freezeCountRemaining on any record is 2 minus the number of freezes used so far in the current streak. When the streak resets (breaks), freezes reset to 2.

    Import `toDayKey` from `../lib/date-utils`, `db` from `../db`, `differenceInCalendarDays` from `date-fns`.
